# Student Marks Details

The **Student Marks Details** project is a data analysis and visualization project. It shows student details along with their marks.

The project uses **Python, Pandas, Matplotlib, and Streamlit** to analyze student performance and show the results in a simple and interactive way.

## 🎯 Objectives

- Analyze student marks and academic performance.
- Calculate useful statistics from the student data.
- Create visualizations using Matplotlib.
- Show student details in an interactive Streamlit application.
- Understand patterns and differences in student performance.

## 🛠️ Technologies Used

- **Python**
- **Pandas** – Used for data analysis and data manipulation.
- **Matplotlib** – Used for data visualization.
- **Streamlit** – Used to create the interactive web application.
- **Jupyter Notebook** – Used for data analysis and experimentation.

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/likithatummapala/Student-Marks-Details.git
```

### 2. Open the Project Folder

```bash
cd Student-Marks-Details
```

### 3. Install Required Libraries

```bash
pip install pandas matplotlib streamlit jupyter
```

Or, if a requirements file is available:

```bash
pip install -r requirements.txt
```

### 4. Run the Streamlit Application

```bash
streamlit run app.py
```

The Streamlit application will open in your web browser.

## 💻 Jupyter Notebook

To run the analysis notebook:

```bash
jupyter notebook project.ipynb
```

The notebook contains the data analysis and visualization part of the project.
